## November 28, 2026

  - [How Markdown to PDF works](/markdown-pdf/guide/how-it-works/): the conversion rules, how the preview is kept safe, and why the PDF is made by printing
  - [How the QR code generator works](/qr-code/guide/how-it-works/): error correction versus icon size, and the output formats
- Added this changelog

## November 5, 2026

  - Markdown syntax cheat sheet / Tips for clean PDFs from Markdown

## October 24, 2026

- Launched the [Internet Speed Test](/speed-test/). It measures download, upload, ping and jitter to your nearest Cloudflare data center
  - Six transfers now run in parallel so that fast connections are measured correctly
- The sound meter now follows the international sound level meter standard (IEC 61672-1) for frequency weighting (A, C, Z) and time weighting (Fast, Slow). The default calibration offset for iPhone was revised after measuring side by side with a calibrated sound meter app
- Renamed the audio analysis tool to "Sound Level Meter"

## October 23, 2026

- Launched the [Sound Level Meter](/sound-meter/). It measures the sound around you with your microphone and shows an estimated dB level, the dominant frequency and a breakdown by frequency range. Nothing is recorded or sent
- Fixed bugs where the calibration offset couldn't be entered and the microphone didn't start and stop reliably

## October 22, 2026

- Image converter: tightened the size and file-count limits when extracting ZIP files and when reloading, so that extremely large inputs can't freeze the browser
- Limited how much embedded metadata (such as EXIF) is read from images
- Updated the libraries used for WebP and GIF processing to versions that fix known vulnerabilities
- Updated the Markdown to PDF conversion library to a version that fixes vulnerabilities that could make processing extremely slow

## October 21, 2026

- Reorganised the header and added tabs to switch between the pages within a tool (convert, compress, icon generator and so on)
- Added a short list of what each tool can do to the home page
- Collapsed advanced settings, URL input and FAQs on the tool screens so the first step is easier to find

## October 20, 2026

- Launched the site on its own domain (t0n03k1.com) with three tools
  - [Image Converter & Compressor](/image-adjust/): convert between PNG, JPEG and WebP, compress while keeping quality, and generate favicon and app icon sets
  - [Markdown to PDF](/markdown-pdf/): preview as you write, choose paper size, margins and font size, and save as PDF
  - [QR Code Generator](/qr-code/): create a QR code from a URL, add a logo or icon in the center, and save as PNG or SVG
- Available in Japanese and English, with light and dark themes

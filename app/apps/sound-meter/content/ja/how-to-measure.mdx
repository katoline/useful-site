スマートフォンがあれば、アプリやブラウザで手軽に騒音を測れます。ただ、同じ場所で測っても、持ち方や設定、見る値によって数字は大きく変わります。この記事では、[騒音計で測る](/)ときに知っておきたい設定の意味（周波数と時間の重み付け）、結果の読み方（平均・最大・L90 など）、スマートフォンのマイクの限界と校正のしかた、測るときの実際のコツをまとめます。dB という単位そのものや、身近な音の大きさの目安は、[騒音の大きさの目安：dB と身近な音の比較](/guide/noise-levels/)を参照してください。

## 周波数の重み付け：A・C・Z の違い

### 人の耳は、低い音を小さく感じる

人の耳は、1kHz〜4kHz あたりの音にいちばん敏感で、低い音やとても高い音は、同じエネルギーでも小さく聞こえます。騒音計は、この聞こえ方に合わせて周波数ごとに割り引いてから大きさを数えます。これが周波数の重み付けで、国際規格 IEC 61672-1 で A・C・Z の 3 種類が決められています。この騒音計も、同じ規格の式にもとづくデジタルフィルタで重み付けをしています。

| 周波数 | A 特性 | C 特性 | Z 特性 |
| --- | --- | --- | --- |
| 31.5Hz | 約 -39dB | 約 -3dB | 0dB |
| 63Hz | 約 -26dB | 約 -1dB | 0dB |
| 125Hz | 約 -16dB | 約 0dB | 0dB |
| 250Hz | 約 -9dB | 0dB | 0dB |
| 500Hz | 約 -3dB | 0dB | 0dB |
| 1kHz | 0dB | 0dB | 0dB |
| 4kHz | 約 +1dB | 約 -1dB | 0dB |
| 8kHz | 約 -1dB | 約 -3dB | 0dB |

### どれを選べばよいか

- **A 特性（既定）**：人が感じるうるささに近く、騒音の評価や環境基準はふつう A 特性の値（dB(A)）で表します。迷ったら A を使ってください。
- **C 特性**：低い音をほとんど割り引きません。エンジン音、重低音の音楽、室外機のうなりなど、低い音が多い騒音を調べるときに、A 特性の値と比べると役立ちます。C 特性の値が A 特性より 10dB 以上大きければ、低い音が多く含まれていると考えられます。
- **Z 特性**：重み付けをしない、そのままの大きさです。音の物理的な大きさを見たいときに使います。

市販の騒音計や他のアプリと比べるときは、**必ず同じ重み付けにそろえて**ください。低い音が多い場所では、A と C で 10dB 以上違うこともあります。

## 時間の重み付け：Fast と Slow

騒音計の表示は、音の変化にどれだけ速く付いていくかを決める「時間の重み付け」をかけた値です。

- **Fast（0.125 秒）**：音の変化にすばやく付いていきます。車の通過やドアの音のような短い音の最大値をとらえやすく、環境の騒音を測るときに一般的に使われます。
- **Slow（1 秒）**：値の動きがゆるやかになり、読み取りやすくなります。エアコンや換気扇のように、ほぼ一定の音を眺めるのに向いています。

この騒音計では、画面の「いまの音」、最大（Lmax）、最小（Lmin）、L10・L50・L90 がこの設定の影響を受けます。一方、平均（Leq）は届いた音すべてのエネルギーを平均した値なので、Fast と Slow のどちらでも基本的に同じです。短い大きな音は Fast の方が最大値が大きく出るので、最大値を比べるときは設定をそろえてください。

## 結果の値の読み方と使い分け

計測が終わると、いくつもの値が表示されます。それぞれ答えてくれる問いが違います。

| 値 | 意味 | 向いている使い方 |
| --- | --- | --- |
| 平均（Leq） | 計測時間のエネルギーの平均 | その時間の代表値。環境基準との比較 |
| 最大（Lmax） | 時間の重み付けをかけた値の最大 | 車の通過、足音など、一時的な大きな音 |
| 最小（Lmin） | 時間の重み付けをかけた値の最小 | いちばん静かになった瞬間 |
| L10 | 計測時間の 10% でこれを超えた | うるさい時の目安 |
| L50 | 中央値 | ちょうど真ん中の大きさ |
| L90 | 計測時間の 90% でこれを超えた | 話し声などを除いた、ふだんの音（暗騒音） |
| 瞬間最大（ピーク） | 重み付けをしない瞬間の最大 | 手をたたいた音などの鋭い音の確認 |

### 平均（Leq）は「ふつうの平均」ではない

Leq はエネルギーで平均するため、大きな音に強く引っ張られます。たとえば 60 秒のうち、10 秒間だけ 80dB の音があり、残り 50 秒は 50dB だったとします。dB の数字をそのまま平均すると 55dB ですが、Leq は約 72dB になります。「たまにしか鳴らない大きな音」が、聞く人にとっての負担を大きく左右することを表した数え方です。環境基準もこの Leq で決められています。

### L90 で「もともとの静かさ」を知る

L90 は、計測時間の 90% でこの大きさを超えていた、という値です。ときどき通る車や話し声に影響されにくく、その場所の「何も起きていないときの音」の目安になります。たとえば、新しく置かれた室外機の音がどのくらい増えたかを調べるなら、置かれる前と後の L90 を比べると分かりやすくなります。

### 最大と平均を一緒に見る

平均は小さいのに最大が大きいなら、ふだんは静かでも、ときどき大きな音がする環境です。夜に目が覚めるといった悩みは、平均よりも最大の値と回数に関係していることがあります。逆に、平均と L90 が近ければ、ほぼ一定の音がずっと続いている環境です。

### 周波数の情報

この騒音計は、大きさに加えて、主な周波数（音名つき）、音の明るさ（スペクトル重心）、低音〜高音の 4 つの音域の内訳も表示します。低音（20〜250Hz）の割合が大きければ、エンジン、室外機、足音、重低音の音楽などが主な音源だと推測できます。音源が分かると、窓を二重にする、防振ゴムを敷くなど、どんな対策が効きそうかを考えやすくなります。

## スマホ・パソコンのマイクの限界

スマートフォンやパソコンのマイクは、通話や録音のための部品で、騒音を測るために作られてはいません。次のような限界があることを知っておくと、結果を読み違えにくくなります。

### 感度は機種ごとに違う

マイクの感度は機種によって違い、校正もされていません。この騒音計は、マイクが拾った大きさ（デジタルの最大値を 0 とした dBFS）に補正値を足して推定 dB を求めています。補正値の既定値は、iPhone・iPad では校正済みの騒音計アプリと並べて測って決めた +122dB、それ以外の端末では暫定の +100dB です。特に Android やパソコンでは、実際の値から大きくずれることがあります。

### 音の加工が入ることがある

多くの端末は、通話を聞きやすくするために雑音抑制、自動音量調整、エコー除去をかけます。この騒音計はこれらを止めるようブラウザに求めていますが、端末によっては止められません。止められなかったときは画面に案内が出ます。その場合、静かな音が実際より小さく出たり、音量の変化がならされたりすることがあります。

### とても小さい音・大きい音・低い音は苦手

- **とても静かな場所**：マイク自身の雑音より小さい音は測れません。30dB を下回るような静かな部屋では、実際より大きめに出ることがあります。
- **とても大きな音**：マイクや内部の回路が頭打ちになり、実際より小さく出ることがあります。ライブ会場や工事現場の近くでは注意してください。
- **低い音**：小さなマイクは低い音を拾いにくいので、C 特性・Z 特性の値は、特に 100Hz を下回る低い音を少なめに数えがちです。

## 基準の騒音計に合わせる（校正）

手元に市販の騒音計や校正済みの騒音計アプリがあれば、それに合わせて補正値を調整できます。

1. 基準の騒音計と、この騒音計の重み付け（A・C・Z、Fast・Slow）をそろえます。
2. 2 台をできるだけ近づけ、同じ方向に向けます。
3. 換気扇やエアコンのような、大きさが一定の音が続く場所を選びます。静かすぎる場所は避け、50〜70dB くらいの音で合わせるのがおすすめです。
4. 同じ時間に 30 秒程度測ります。基準の騒音計の平均（Leq・AVG などと表示される値）を読み取ります。
5. 計測結果の下の「基準に合わせる」にその値を入れ、「この値に合わせる」を押します。

この計測の平均が基準の値と同じになるよう補正値が決まり、端末に保存されて次回から使われます。設定の「既定に戻す」で元に戻せます。

1 か所の大きさで合わせているので、ほかの大きさでも同じだけ合うとは限りません。何度か別の音でも並べて測り、差を確かめておくと安心です。また、ブラウザや端末を変えたとき、外付けのマイクやイヤホンをつないだときは、合わせ直してください。

## 正しく測るための実践的なコツ

### 端末の持ち方と置き方

- **マイクの穴をふさがない**：スマートフォンのマイクは、多くの場合本体の下の端にあります。指やケース、ポケットでふさぐと、値が大きく下がります。
- **体から離す**：体は音を跳ね返したりさえぎったりします。腕を伸ばすか、台に置いて測ると安定します。環境の騒音を測るときは、一般に地面から 1.2〜1.5m くらいの高さで測ります。
- **壁や机に近づけすぎない**：反射した音が重なり、値が変わります。壁や窓から 1m 程度離すのがひとつの目安です。
- **計測中は動かさない・触らない**：手で触れた音や、こすれる音はマイクに直接届き、最大値を大きく押し上げます。

### 機器の準備

- **Bluetooth のイヤホンや外付けマイクを外す**：つながっていると、そちらのマイクで測ってしまいます。Bluetooth の通話用マイクは、音の加工が強く、高い音も切られています。
- **ほかのアプリでマイクを使っていないか確かめる**：通話アプリやボイスレコーダーが動いていると、マイクを使えないことがあります。
- **屋外では風に注意**：風がマイクに当たると、大きな低い音として数えられます。風の強い日や雨の日は避け、建物の陰などで測ります。

### 測る回数と時間

- **何回か測る**：1 回の計測は、たまたまの音に左右されます。同じ条件で 3 回ほど測り、平均（Leq）がそろっているかを確かめます。
- **計測時間を音に合わせる**：一定の音なら 10 秒で足ります。車の通過や電車など、変化のある音は 60 秒で測り、それを何回か繰り返します。
- **時間帯を変えて測る**：騒音は時間帯で大きく変わります。昼と夜、平日と休日などで比べると、問題になっている時間がはっきりします。

### 条件を記録する

あとで比べられるように、次のことを書き留めておきます。

- 日時、場所（部屋、窓からの距離など）、窓を開けていたか閉めていたか
- 使った端末と、重み付けの設定（A・C・Z、Fast・Slow）
- 平均・最大・L90 の値
- そのとき聞こえていた音（車、工事、話し声など）

計測結果の「CSV を保存」で、0.1 秒ごとの値を表計算ソフトで開ける形で保存できます。どの時刻に大きな音がしたかを後から確かめるのに便利です。音そのものは録音していません。

## 近所や道路の騒音を確かめたいとき

隣の部屋の音や道路の騒音が気になるとき、スマートフォンで測った値は「どの時間帯に、どのくらい大きいのか」を把握する手がかりになります。時間帯ごとの記録があれば、管理会社や相手に状況を伝えるときにも、感覚だけで話すより具体的になります。

ただし、スマートフォンの値はあくまで推定です。裁判や公的な申し立てなど、数値が証拠になる場面では、計量法の検定を受けた騒音計で、決められた方法で測る必要があります。自治体の環境の担当窓口に相談すると、測り方を教えてもらえたり、騒音計を貸してもらえたりすることがあります。

## まとめ

- 迷ったら A 特性・Fast で測り、比べる相手とは重み付けをそろえます。
- 代表値は平均（Leq）、一時的な大きな音は最大、ふだんの静かさは L90 で見ます。
- スマートフォンのマイクには限界があります。基準の騒音計があれば「基準に合わせる」で校正します。
- マイクをふさがず、体から離し、何回か、時間帯を変えて測り、条件を記録します。

準備ができたら、さっそく[騒音計で測る](/)ところから始めてみてください。測った値がどのくらいの大きさなのかは、[騒音の大きさの目安](/guide/noise-levels/)の表と比べると分かりやすくなります。そのほかの解説は[解説の一覧](/guide/)にあります。

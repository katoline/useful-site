## Image Adjust について

Image Adjust は、Web サイトや LP の制作で使う画像を、ブラウザだけで変換・圧縮・最適化できる無料のツールです。PNG・JPEG・WebP の相互変換、画像の圧縮とリサイズ、ファビコンなど Web 用アイコン一式の生成ができます。会員登録は不要で、ページを開けばすぐに使えます。

## 使い方

### 変換・圧縮ツール

[変換・圧縮ツール](/)では、画像の形式を変えたり、ファイルサイズを小さくしたりできます。

1. 画像を読み込みます。ファイルを選ぶ、ドラッグ＆ドロップする（PC のみ）、フォルダや ZIP ファイルをまとめて入れる、画像の URL を指定する、のいずれかの方法が使えます。
2. 出力する形式（PNG・JPEG・WebP）と、圧縮の方法を選びます。品質をスライダーで指定する、「200KB 以下」のように目標のファイルサイズを指定する、幅・高さや縮小率でリサイズする、を組み合わせられます。
3. 処理前後のサイズと削減率が一覧で表示されます。スライダーで処理前と処理後の見た目を比べ、問題がなければ 1 枚ずつ、または ZIP でまとめてダウンロードします。

透過を含む画像を JPEG にする場合は、透過部分を塗る背景色（既定は白）を指定できます。写真に含まれる位置情報などのメタデータ（EXIF）は、既定で削除されます。

### アイコン生成ツール

[アイコン生成](/icons/)では、1 枚の元画像から、Web サイトに必要なアイコン一式をまとめて作れます。元画像は正方形の SVG か PNG（512px 以上）がおすすめです。

- favicon.ico、各サイズの PNG、Apple Touch Icon、PWA 用のアイコン（maskable を含む）、Web App Manifest、OGP 画像を ZIP で書き出します。
- 余白・背景色・角丸を調整でき、16px・32px で表示したときの見え方や、ライト・ダーク両方のブラウザタブでの見え方をプレビューで確認できます。
- サイトの HTML に貼り付けるためのコードも生成するので、コピーしてそのまま使えます。

画像形式の選び方やファビコンの設置方法は、[ガイド](/guide/)で詳しく解説しています。

### アプリとしてインストールする（PWA）

Image Adjust は PWA（プログレッシブ Web アプリ）に対応しており、スマートフォンや PC にアプリとしてインストールできます。

- **Android・PC の Chrome / Edge**：画面に表示されるインストールボタン、またはブラウザのメニューの「アプリをインストール」から追加できます。
- **iPhone・iPad**：Safari の共有ボタンから「ホーム画面に追加」を選びます。

インストール後は、一度読み込んだアプリ本体が端末に保存されるため、圏外やオフラインでも変換・圧縮・アイコン生成を使えます。ただし、画像 URL からの読み込みと広告の表示にはインターネット接続が必要です。

Android では、ギャラリーなど他のアプリの「共有」から Image Adjust を選ぶと、その画像をそのまま変換画面に読み込めます。PC の Chrome / Edge では、画像ファイルを「このアプリで開く」こともできます。新しいバージョンがあるときは画面にお知らせが出るので、再読み込みすると切り替わります。

### 言語とテーマの切り替え

画面上部のメニューから、表示言語（日本語 / English）とテーマ（ライト / ダーク / 端末の設定に従う）を切り替えられます。画像を読み込んだ後に言語を切り替えても、作業中の画像や設定は失われません。選んだ言語とテーマはお使いの端末に保存され、次回も同じ表示で開きます。

## このサイトの特徴

### 画像はブラウザの中で処理します

画像の変換・圧縮・アイコン生成は、すべてお使いのブラウザの中で行います。読み込んだ画像を運営者のサーバーに送信したり、保存したりすることはありません。社外秘の資料や個人の写真も、端末の外に出さずに処理できます。

唯一の例外は、画像の URL を指定して読み込む機能です。ブラウザから他のサイトの画像を直接取得すると、ブラウザの制限（CORS）によって失敗することが多いため、この機能を使ったときだけ、指定された URL を運営者の中継サーバーに送り、中継サーバーがその画像を取得してブラウザに返します。中継サーバーは画像も URL も保存しません。詳しくは[プライバシーポリシー](/privacy/)をご覧ください。

### 無料・登録不要

すべての機能を無料で、アカウント登録なしで使えます。運営費は、ページに掲載している広告の収益でまかなっています。

### 大きな画像やまとめての処理にも対応

複数の画像やフォルダ、ZIP ファイルをまとめて処理できます。扱える画像の大きさは、お使いの端末の性能（メモリ）によって決まります。端末で扱いきれない大きさの画像は処理を飛ばしてお知らせするので、PC で試すか、縮小してから読み込んでください。

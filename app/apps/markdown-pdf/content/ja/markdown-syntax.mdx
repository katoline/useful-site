Markdown（マークダウン）は、記号を少し添えるだけで見出しや箇条書きを表せる、テキストの書き方です。メモ帳のようなエディターで書けて、そのままでも読みやすく、HTML や PDF に整えて出力できます。

この記事では、よく使う記法を「書き方」と「どう表示されるか」の組で紹介します。どれも [Markdown を PDF にする](/)ツールでそのまま使えます。ツールの「サンプルを挿入」を押すと、ここで紹介する記法の多くを含んだ例文が入るので、見比べながら読むと分かりやすいはずです。

## 見出し

行の先頭に `#` を置くと見出しになります。`#` の数が見出しのレベルで、1 個から 6 個まで使えます。`#` の後には半角スペースを 1 つ入れます（スペースが無いと見出しになりません）。

```markdown
# 文書のタイトル

## 大きな章

### 小さな節

#### さらに細かい項目
```

`#` が 1 個の見出し（h1）は文書のタイトルとして 1 回だけ使い、本文は `##` から始めるのが一般的です。このツールでは、最初の `#` の見出しが PDF の保存名の初期値になります。

見出しのすぐ下に `===` や `---` の線を引く書き方もあります（`===` は h1、`---` は h2 になります）。改ページのつもりで `---` を書いたのに見出しになってしまう原因はこれなので、後述の「水平線と改ページ」も確認してください。

## 段落と改行

1 行以上の空行で区切った文のかたまりが、1 つの段落になります。

```markdown
これは 1 つ目の段落です。
この行は前の行に続けて表示されます。

空行を入れると、ここから 2 つ目の段落になります。
```

Markdown では、行末で改行しただけでは改行になりません。上の例の 1 行目と 2 行目は、つながった 1 つの文として表示されます（日本語の文では、つなぎ目に小さな空白が入って見えることがあります）。

段落を分けずに行だけを変えたいときは、行末に半角スペースを 2 つ置くか、行末にバックスラッシュ `\` を置きます。

```markdown
〒100-0001\
東京都千代田区…\
担当：山田
```

スペース 2 つは目に見えず、エディターによっては保存時に消されてしまうため、バックスラッシュのほうが確実です。

## 強調と取り消し線

```markdown
**太字** にする
*斜体* にする
~~取り消し線~~ を引く
```

`**` で囲むと太字、`*` 1 つで囲むと斜体、`~~` で囲むと取り消し線になります。`*` の代わりに `_` も使えます。日本語の書体には斜体が無いものが多く、斜めに変形した表示になるか、ほとんど変わらないことがあります。日本語の文書で目立たせたいときは太字を使うのが無難です。

記号そのものを表示したいときは、前にバックスラッシュを付けます。たとえば `\*` と書くと、強調にならずに `*` が表示されます。

## 箇条書き

行の先頭に `-`（または `*`・`+`）と半角スペースを置くと箇条書きになります。行頭に半角スペース 2〜4 個を入れて字下げすると、入れ子の箇条書きになります。

```markdown
- 準備するもの
  - ノート PC
  - 電源アダプター
- 当日の流れ
- 連絡先
```

箇条書きの直前に段落があるときは、間に空行を 1 行入れておくと確実です。

## 番号付きリスト

数字とピリオドで始めると、番号付きのリストになります。

```markdown
1. 申請書をダウンロードする
2. 必要事項を書き込む
3. 上長に提出する
```

表示される番号は、最初の項目の数字から順に振り直されます。そのため、すべての行を `1.` と書いても 1・2・3 と表示されます。途中に項目を足したときに番号を書き直さなくて済むので便利です。逆に、`3.` から始めれば 3 から数え始めます。

番号付きリストの中に箇条書きを入れるときは、番号の後ろの文字の位置（`1. ` なら 3 文字分）まで字下げします。

```markdown
1. 申請書を書く
   - 押印は不要です
2. 提出する
```

## タスクリスト（チェックボックス）

箇条書きの `- ` の後に `[ ]` を置くと未完了、`[x]` を置くと完了のチェックボックスになります。

```markdown
- [x] 会場を予約する
- [ ] 資料を印刷する
- [ ] 参加者に案内を送る
```

ToDo や確認項目の一覧に向いています。このツールでは、PDF にしたときにそのまま印刷物として見せることを考え、チェックボックスは書いたときの状態で固定され、画面上でクリックしても切り替わりません。状態を変えたいときは、Markdown の `[ ]` と `[x]` を書き換えます。

## リンク

```markdown
[表示する文字](https://example.com/)
[メールで問い合わせる](mailto:info@example.com)
```

角かっこの中が表示される文字、丸かっこの中が飛び先です。`https://` で始まる URL を文中にそのまま書いた場合も、自動でリンクになります。

このツールのリンクは、http・https・mailto・tel と相対パス・ページ内リンク（`#` で始まるもの）だけを有効にしています。`javascript:` のような危険になりうる URL はリンクにせず、文字のまま表示します。PDF にしたリンクは本文と同じ色で、下線付きで表示されます。保存したブラウザや PDF を開くソフトによっては、PDF の中でもクリックして開けます。

## 画像

画像は、リンクの前に `!` を付けた形で書きます。角かっこの中は、画像が表示できないときや読み上げのときに使われる説明文です。

```markdown
![売上の推移](chart.png)
![構成図](images/diagram.svg)
```

このツールで画像を PDF に入れるには、ツールの「画像を追加」で画像ファイルを入れます（編集欄へのドラッグ＆ドロップでも入ります）。すると、本文に書いた `chart.png` のような相対パスの画像が、入れたファイルで表示されます。照合はまずパスの全体で、見つからなければファイル名で行うので、`images/diagram.svg` と書いてあっても `diagram.svg` というファイルを入れれば表示されます。ファイル名の大文字・小文字の違いも、最後は区別せずに探します。

使える画像は PNG・JPEG・GIF・WebP・AVIF・SVG で、50 枚・合計 20MB までです。`data:image/png;base64,…` のように画像そのものを文字列で埋め込んだ data: の画像も表示できます。

一方、`https://` で始まる外部 URL の画像は読み込みません。外部の画像を読み込むと、その画像のサーバーに「誰がいつ文書を開いたか」が伝わってしまうためです。外部の画像は、代わりに「画像を表示できません」という枠で示します。使いたい画像は、いったん端末に保存してから「画像を追加」で入れてください。

画像の大きさを指定する記法は、標準の Markdown にはありません。画像は横幅が本文の幅に収まるように縮小され、それより小さい画像は元の大きさのまま表示されます。大きさを整えたいときは、画像ファイルそのものを目的の大きさにしておきます。

## 引用

行の先頭に `>` を置くと引用になります。`>` を重ねると、引用の中の引用になります。

```markdown
> 来週の定例は、会議室 B に変更になりました。
>
> > 了解しました。
```

引用は左側に線が付き、文字が少し薄い色で表示されます。他の人の発言やメールの抜き書き、注意書きを目立たせたいときにも使えます。

## コード

文中の短いコードや、コマンド・ファイル名などは、バッククォート `` ` `` で囲みます。

```markdown
設定は `config.json` に書きます。
```

複数行のコードは、バッククォート 3 つの行で前後を囲みます（コードブロック）。最初の 3 つの後ろには、言語名を書いておけます。

````markdown
```js
const total = items.reduce((sum, item) => sum + item.price, 0);
console.log(total);
```
````

コードは等幅の書体で、薄い灰色の背景に表示されます。このツールでは、言語名に応じた色分け（シンタックスハイライト）はしません。印刷では白黒になることも多く、色に頼らないほうが読みやすいためです。言語名は書いておいて構いません（Markdown のファイルを別の場所で使うときに役立ちます）。

コードブロックの中では、`#` や `*` などの記号はそのまま文字として表示されます。Markdown の書き方そのものを説明したいときにも使えます。1 行が長いコードは、紙からはみ出さないよう途中で折り返して表示します。

## 表

縦棒 `|` で列を区切り、2 行目に `---` を並べて見出しの行と本文の行を分けます。

```markdown
| 項目 | 担当 | 期限 |
| :--- | :---: | ---: |
| 設計 | 佐藤 | 10/20 |
| 実装 | 鈴木 | 11/10 |
```

2 行目の `:` の位置で、列ごとの文字の寄せを指定できます。`:---` は左寄せ、`:---:` は中央寄せ、`---:` は右寄せです。金額や日付など、桁をそろえたい列は右寄せにすると読みやすくなります。

各行の列の数は見出しの行とそろえます。列の幅は内容に合わせて自動で決まるので、`|` の位置をそろえる必要はありません（そろえておくと、Markdown のままでも読みやすくなります）。セルの中で改行する方法は標準の記法には無いため、長い文章はセルに入れず、表の下に箇条書きで添えるのがおすすめです。セルの中に `|` を書きたいときは `\|` とします。

## 水平線と改ページ

`---`（または `***`・`___`）だけの行は、区切りの水平線になります。

```markdown
1 章の最後の段落です。

---

## 2 章
```

このツールでは、「--- で改ページする」がオン（初期設定）のとき、水平線の位置で次のページに移ります。プレビューでは、改ページの位置が点線で表示されます。オフにすると、普通の水平線として線が引かれます。

注意したいのは、文の行のすぐ下に `---` を書くと、その行が見出し（h2）になってしまうことです。改ページや区切り線のつもりで書くときは、`---` の前に必ず空行を 1 行入れてください。

また、ブログなどで使う Markdown ファイルには、先頭に `---` で囲んだ「フロントマター」（タイトルや日付などの設定）があることがあります。このツールはフロントマターを特別扱いしないので、そのまま入れると最初の `---` が改ページになり、白紙のページができたり、設定の行が見出しとして表示されたりします。PDF にする前に、先頭のフロントマターを消しておきましょう。

## 脚注

本文の注を付けたい位置に `[^1]` のような印を書き、別の行に `[^1]:` で始まる注の本文を書きます。

```markdown
売上は前年より 12% 増えました[^1]。

[^1]: 返品分を差し引いた金額で比べています。
```

本文の印は小さな番号になり、注の本文は文書の最後にまとめて表示されます（ページごとの下ではなく、文書の末尾です）。`^1` の部分は `[^note]` のような名前でも構いません。番号は出てきた順に 1 から振られます。

## このツールで使えない記法

Markdown の中には HTML のタグを書ける仕様もありますが、このツールは安全のため HTML を解釈しません。たとえば次のように書くと、タグがそのまま文字として表示されます。

```markdown
<span style="color: red">赤い文字</span>
<div align="center">中央寄せ</div>
<br>
```

文字の色・中央寄せ・画像の大きさの指定・セル内の改行など、HTML に頼る書き方は使えません。改行は行末のバックスラッシュ、強調は太字、といった Markdown の記法で表すようにしてください。

ほかにも、次のものは表示されません（または文字のまま残ります）。

- 外部 URL の画像（上の「画像」を参照）
- 数式（`$` で囲む記法）や、Mermaid などで描く図
- 文字の色・下線・文字サイズの部分的な変更

図が必要なときは、別のツールで描いて PNG や SVG に書き出し、「画像を追加」で入れるのが確実です。

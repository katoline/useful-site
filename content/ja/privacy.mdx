Image Adjust（以下「本サービス」）の運営者（以下「運営者」）は、本サービスの利用者の情報を次のとおり取り扱います。

## 画像の取り扱い

本サービスでの画像の変換・圧縮・アイコン生成は、すべて利用者のブラウザの中で行います。利用者が読み込んだ画像や、処理した結果の画像を、運営者のサーバーに送信したり保存したりすることはありません。

### 画像 URL を指定して読み込む場合

「画像 URL を指定して読み込む」機能を使った場合に限り、次のように運営者の中継サーバーを経由します。

- 利用者が入力した URL を、運営者の中継サーバー（Cloudflare Workers 上で動作します）に送信します。
- 中継サーバーがその URL から画像を取得し、利用者のブラウザにそのまま返します。取得した画像の処理は、ほかの機能と同じくブラウザの中で行います。
- 中継サーバーは、取得した画像も、入力された URL も保存しません。
- ただし、サービスの運用と不正利用の防止（回数制限）のため、Cloudflare, Inc. のシステムが IP アドレス、リクエストの URL、User-Agent などのアクセスログを一時的に記録することがあります。

この機能を使わない限り、画像に関する情報が運営者のサーバーに送られることはありません。

## 広告について

本サービスは、第三者配信の広告サービス「Google AdSense」を利用しています。

- Google などの第三者配信事業者は、Cookie を使用して、利用者が本サービスや他のサイトに過去にアクセスした際の情報に基づいて広告を配信します。
- Google は広告 Cookie を使用することにより、利用者が本サービスや他のサイトにアクセスした際の情報に基づいて、Google やそのパートナーが適切な広告を表示できるようにしています。
- 利用者は、[Google の広告設定](https://adssettings.google.com)でパーソナライズ広告を無効にできます。また、[www.aboutads.info](https://www.aboutads.info/choices/) にアクセスすれば、パーソナライズ広告に使われる第三者配信事業者の Cookie を無効にできます。
- Google による広告での情報の扱いについては、[Google の広告に関するポリシー](https://policies.google.com/technologies/ads)と、[Google のサービスを使用するサイトやアプリから収集した情報の Google による使用](https://policies.google.com/technologies/partner-sites)をご覧ください。

広告を配信するため、本サービスのページ内では Google などの第三者が提供するスクリプトが動作します。本ポリシーや本サービスの画面にある「画像はサーバーに送信しない」という記載は、運営者のサーバーについてのものです。広告のスクリプトは、上記のとおり Cookie やアクセス情報を第三者配信事業者に送信しますが、利用者が本サービスで読み込んだ画像そのものを送信するものではありません。

欧州経済領域（EEA）、英国、スイスからアクセスする利用者には、Google 認定の同意管理プラットフォーム（CMP）を通じて、Cookie などの使用について同意を取得します。同意の内容は、表示されるメッセージから選択・変更できます。

## アクセス解析について

本サービスは、利用状況を把握してサービスを改善するため、アクセス解析ツール「Cloudflare Web Analytics」を利用しています。

- Cloudflare Web Analytics は Cookie を使用しません。
- 閲覧したページの URL、参照元（どのページから来たか）、ブラウザや OS の種類、ページの表示速度などを集計します。個人を特定する目的では使用しません。
- Cloudflare による情報の取り扱いは、[Cloudflare のプライバシーポリシー](https://www.cloudflare.com/privacypolicy/)をご覧ください。

## 端末内に保存する情報

本サービスは、利用者の端末（ブラウザ）の中に次の情報を保存します。いずれも端末の中にとどまり、運営者に送信されることはありません。

- **表示の設定**：選んだテーマと言語を、ブラウザの localStorage に保存します。同じドメインで動く他のサービスと区別するため、保存する項目の名前には「image-adjust:」という接頭辞を付けています。
- **アプリ本体**：オフラインでも使えるようにするため、本サービスのプログラム（HTML・JavaScript・CSS など）を Service Worker と Cache Storage に保存します。
- **共有で受け取った画像**：他のアプリの「共有」から本サービスに画像を渡した場合、その画像を変換画面に渡すまでの間だけ、端末内のキャッシュに一時的に置きます。変換画面が受け取った後に削除します。

これらの情報は、ブラウザの設定からサイトのデータを削除することで、いつでも消去できます。

## 個人情報の取り扱い

本サービスは会員登録の仕組みを持たず、利用にあたって氏名やメールアドレスなどの個人情報を求めることはありません。

お問い合わせフォーム（Google フォーム）から、お名前・メールアドレス・お問い合わせ内容などをお送りいただいた場合、運営者はその情報を次のとおり取り扱います。

- お問い合わせへの回答と、本サービスの改善のためにのみ利用します。
- 法令に基づく場合などを除き、ご本人の同意なく第三者に提供しません。
- 不要になった情報は、適切な方法で削除します。
- お問い合わせフォームの情報は、Google LLC のサービス上に保存されます。

ご自身の個人情報の開示・訂正・削除を希望される場合は、お問い合わせフォームからご連絡ください。ご本人であることを確認したうえで、合理的な範囲で速やかに対応します。
